# 自考真题模拟与学习系统

> 一站式自学考试备考平台：真题模拟 × 题库检索 × 视频资源 × 高频考点 × 智能规划

为自考考生打造**从刷题 → 搜题 → 看视频 → 抓重点 → 定计划**的完整闭环学习平台，告别碎片化备考，用数据驱动学习方向，用智能规划提升通过率。

## 🚀 快速开始

### 环境要求
- Python 3.9+
- PostgreSQL 13+
- Redis 6+
- Elasticsearch 8+ (可选，用于全文搜索)
- Node.js 16+ (前端开发)

### 安装部署

```bash
# 1. 克隆仓库
git clone https://github.com/zccztt/self-study-exam-hub.git
cd self-study-exam-hub

# 2. 安装后端依赖
pip install -r requirements.txt

# 3. 配置环境变量
cp .env.example .env
# 编辑 .env 文件，配置数据库连接、API密钥等

# 4. 初始化数据库
python manage.py migrate
python manage.py load_initial_data  # 导入初始题库数据

# 5. 启动后端服务
python manage.py runserver

# 6. 安装前端依赖（另开终端）
cd frontend
npm install

# 7. 启动前端开发服务器
npm run dev
```

访问 `http://localhost:3000` 开始使用。

### 🗓️ 模块五：智能学习规划

基于个人薄弱点和考试时间，生成个性化学习计划。

```
┌───────────────────────────────────────────────────────────┐
│                  学习规划引擎                               │
│                                                             │
│  输入                    处理                    输出        │
│  ────                    ────                    ────        │
│                                                             │
│  ┌──────────┐      ┌───────────────┐      ┌────────────┐  │
│  │• 考试日期│      │               │      │ 每日学习   │  │
│  │• 报考科目│      │  规划算法引擎  │      │ 任务清单   │  │
│  │• 每日可用│─────▶│               │─────▶│            │  │
│  │  学习时长│      │ ┌───────────┐ │      │ ┌────────┐ │  │
│  │• 模考成绩│      │ │薄弱点权重 │ │      │ │Day 1   │ │  │
│  │• 错题分布│      │ │计算       │ │      │ │ 9:00   │ │  │
│  │• 学习偏好│      │ ├───────────┤ │      │ │ 第3章  │ │  │
│  └──────────┘      │ │时间分配   │ │      │ │ 刷题20 │ │  │
│                    │ │优化       │ │      │ │ 视频×2 │ │  │
│                    │ ├───────────┤ │      │ ├────────┤ │  │
│                    │ │遗忘曲线   │ │      │ │Day 2   │ │  │
│                    │ │复习排期   │ │      │ │ ...    │ │  │
│                    │ ├───────────┤ │      │ └────────┘ │  │
│                    │ │进度自适应 │ │      │            │  │
│                    │ │调整       │ │      │ 📊 甘特图  │  │
│                    │ └───────────┘ │      │ 📈 进度条  │  │
│                    └───────────────┘      └────────────┘  │
└───────────────────────────────────────────────────────────┘
```

**核心算法**：
1. **薄弱点识别**：基于模考成绩和错题分布计算知识点掌握度
2. **时间分配优化**：根据考试倒计时和每日可用时长动态分配学习任务
3. **遗忘曲线复习**：基于艾宾浩斯遗忘曲线安排复习节点
4. **进度自适应调整**：根据实际完成情况动态调整后续计划

**输出内容**：
- 每日学习任务清单（章节、题量、视频数）
- 可视化甘特图和进度条
- 预计通过率和薄弱点警告

## 🛠️ 技术栈

### 后端
- **框架**: FastAPI / Django REST Framework
- **数据库**: PostgreSQL (主数据库)
- **缓存**: Redis (会话、排行榜)
- **搜索引擎**: Elasticsearch (全文搜索)
- **对象存储**: MinIO (图片、附件)
- **AI 能力**: Unity2.ai API (Codex、Claude 模型，用于智能解析和规划)

### 前端
- **框架**: React / Vue 3
- **语言**: TypeScript
- **样式**: Tailwind CSS
- **可视化**: ECharts / D3.js
- **状态管理**: Redux / Pinia

### 部署
- **容器化**: Docker + Docker Compose
- **网关**: Nginx / Kong
- **监控**: Prometheus + Grafana
- **日志**: ELK Stack

## 🔑 核心配置

编辑 `.env` 文件，配置以下关键参数：

```bash
# 数据库
DATABASE_URL=postgresql://user:password@localhost:5432/exam_hub

# Redis
REDIS_URL=redis://localhost:6379/0

# Elasticsearch
ELASTICSEARCH_URL=http://localhost:9200

# MinIO
MINIO_ENDPOINT=localhost:9000
MINIO_ACCESS_KEY=your_access_key
MINIO_SECRET_KEY=your_secret_key

# Unity2.ai API（用于 AI 功能）
UNITY2_API_KEY=your_unity2_api_key
UNITY2_MODEL=claude-sonnet-4-6  # 或 codex

# JWT 密钥
SECRET_KEY=your_secret_key_here

# 前端地址
FRONTEND_URL=http://localhost:3000
```

## 📊 数据导入

初始化题库和视频数据：

```bash
# 导入题库数据（支持 JSON/CSV 格式）
python scripts/data_import.py --type questions --source data/questions/

# 导入视频元数据
python scripts/data_import.py --type videos --source data/videos/

# 导入知识点库
python scripts/data_import.py --type knowledge --source data/knowledge_base/
```
